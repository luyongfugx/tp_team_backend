# Team Web 与照片分享页本地化

本次为项目现有的 112 个语言/地区补齐 Team Web 和公开照片分享页文案。译文由 Astra 直接编写；脚本仅去重、映射文案键和校验，不调用翻译服务。

## 范围与来源

- `lib/workspace/i18n.ts`：184 个团队工作台文案键，包括筛选、详情、分享权限说明、ZIP/Excel 下载、下载进度和错误提示。
- `lib/web/share-copy.ts`：80 个照片分享页文案键，包括图库、表格、地图、筛选入口、打印、Excel 表头和查看链接。
- `lib/teamspace/locales/*.json`：除英文、简体中文、繁体中文外的语言包；各包均包含上述两个完整命名空间。相同源文案统一译法，地区版本按用词差异处理。
- `lib/teamspace/gps-labels.json`：旧版纯文字 Excel 接口的两个 GPS 经纬度表头，覆盖全部语言，保留原有列顺序和数据。
- 已有账号、管理后台和 App 文案仍由原有本地化系统管理，本次没有重新翻译它们。

## 加载与显示

每次只加载所选语言的资源。分享页在服务端提供该语言文本；登录后的工作台预先加载目标语言，再更新界面，避免切换时卸载照片选择和下载面板。

阿拉伯语、埃及阿拉伯语、希伯来语、波斯语、乌尔都语、普什图语、意第绪语和迪维希语使用从右向左布局。照片与地图不做镜像。照片导航的按键和滑动方向与布局保持一致。浏览器没有对应语言日期词库时使用数字日期，避免混入英文月份。

Excel 使用本地化表头、工作表名称、预览缺失说明和查看链接文字。照片原始名称、成员名、项目名、地址及拍摄时间数据保持原值。表头允许换行，右向左语言使用相应工作表方向。

## 维护与验证

新增界面文案时，同时更新两份基础文案和所有语言包。不得以英文复制填充非英文语言。保留文件名占位符、权限含义和文件数量/大小限制。

自动检查验证覆盖和格式，不能代替母语审校。少数低资源语言的技术名词采用本地借词或完整描述，后续可结合当地用户反馈校对用词。

```sh
node --import tsx --test scripts/teamspace-i18n.test.ts scripts/teamspace-export-i18n.test.ts
node --import tsx --test scripts/workspace-download.test.ts scripts/workspace.test.ts scripts/excel-photos.test.ts scripts/auth.test.cjs
```

第一组检查完整键集、占位符、限制数字和固定格式名，并逐语言生成和重新读取 Excel，验证表头、查看链接、原始文件名和拍摄时间。第二组覆盖现有鉴权、选择、时区、下载和缩略图行为。

本地集成回归使用带数据库保护的 `workspace-excel.integration.ts` 和 `excel-photos.integration.ts`，包含团队/项目/成员权限、筛选、48/200 张图片导出；不得针对生产数据库运行这些夹具脚本。

2026-09-15 验证结果：228 项本地化与 Excel 读回检查、20 项现有行为测试通过；本地带图导出集成回归通过，48 张约 3.29 MB、200 张约 13.69 MB。生产构建成功，抽查德语、越南语、阿拉伯语和迪维希语均输出独立语言资源。桌面与手机布局抽查覆盖越南语、德语、阿拉伯语和印地语；切换语言保留勾选状态。全量 TypeScript 检查仍有 21 处原有错误，位于旧接口和管理后台，本次修改没有新增错误。
