# 手机分享页与看图

团队、项目和成员公开分享页共用本次调整。参考用户提供的 Timemark 手机截图，以及分享页的 390px 窄屏检查。

手机宽度不超过 760px 时，标题等介绍随页面滚走，置顶只保留下载操作和视图切换两行。下载按钮横向滚动；项目、成员、日期、类型和搜索收进筛选入口，收起不重置条件。已筛选时显示蓝色标记。图库两列排列，卡片不重复显示拍摄人和时间文案。

手机单图使用独立轻量预览：默认不显示详情、缩略图条和工具栏；图片完整适配屏幕，轻点返回，双击或双指缩放，放大后拖动，原始比例时左右滑动切图。详情和下载在信息入口内，视频保留原生播放控件。缩放限制为 1–4 倍，拖动边界按实际图片比例计算；多指松开或手势取消不会误触关闭。桌面沿用原有完整预览。

复用原有照片 URL、选择状态、分页与筛选请求，未修改鉴权或服务端接口。新增的筛选入口已覆盖全部 112 个语言/地区。

验证：

- Chrome 390px、320px 窄屏无横向溢出；折叠置顶区 116px 高。
- 浏览器检查双击缩放、拖动切图、轻点返回、勾选保留、日期条件保留、桌面完整详情及阿拉伯语布局。
- 237 项测试通过，包含四组手势单元检查、112 个语言完整性与 Excel 读回、现有图库选择和权限测试。
- `npm run build` 成功；TypeScript 仍只有原有 21 处旧接口/管理后台错误。
- 双指行为通过手势逻辑测试，尚未在实体 iPhone/Android 上做触控回归。
