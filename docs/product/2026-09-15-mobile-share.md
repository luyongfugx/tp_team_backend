# 手机分享页与看图

团队、项目和成员公开分享页共用本次调整。参考用户提供的 Timemark 手机截图，以及分享页的 390px 窄屏检查。

手机宽度不超过 760px 时，标题等介绍随页面滚走，置顶只保留下载操作和视图切换两行。下载按钮横向滚动；项目、成员、日期、类型和搜索收进筛选入口，收起不重置条件。已筛选时显示蓝色标记。图库两列排列，卡片不重复显示拍摄人和时间文案。

手机单图使用独立轻量预览：默认不显示详情、缩略图条和工具栏；图片完整适配屏幕，轻点返回，双击或双指缩放，放大后拖动，原始比例时左右滑动切图。详情和下载在信息入口内，视频保留原生播放控件。缩放限制为 1–4 倍，拖动边界按实际图片比例计算；多指松开或手势取消不会误触关闭。桌面沿用原有完整预览。

复用原有照片 URL、选择状态、分页与筛选请求，未修改鉴权或服务端接口。新增的筛选入口已覆盖全部 112 个语言/地区。

验证：

- 浏览器检查双击缩放、拖动切图、轻点返回、勾选保留、日期条件保留、桌面完整详情及阿拉伯语布局。
- 237 项测试通过，包含四组手势单元检查、112 个语言完整性与 Excel 读回、现有图库选择和权限测试。
- `npm run build` 成功；TypeScript 仍只有原有 21 处旧接口/管理后台错误。
- 双指行为通过手势逻辑测试，尚未在实体 iPhone/Android 上做触控回归。

## 工作区身份、筛选与复制（第二轮）

- 团队、项目、成员页面显示「名称 · 工作区」、范围及所属团队等说明；下载采用次要按钮。通过工作区分享入口生成的链接会保存并校验分享人，显示「分享人 · 通过 Timeprint 分享」。旧的直接链接不推断分享人，成员跨团队页面不虚构所属团队。
- 手机筛选改为底部面板，包含项目、成员、类型、搜索，以及今天、昨天、本周、本月和自定义日期。已固定的成员/项目显示为范围信息，不提供无效下拉框。条件标签可以逐项移除，筛选数量显示在入口；桌面保留紧凑筛选行。按天增加 Excel 导出。
- 已登录且有管理权限时显示「复制到」主按钮。服务端校验来源和目标团队权限，单次最多 200 项；目标项目加锁后按资产身份去重，重复提交不会新增重复记录。复制保留照片、视频和拍摄信息，创建新的目标项目记录；不移动原记录，不重新上传媒体。已删除的旧副本不妨碍重新复制。
- 地图从独立接口读取筛选范围的位置统计，不依赖图库当前页。每次最多 1000 个位置，更多位置由「加载更多」继续；显示已载照片数/结果总数及缺失 GPS 数。屏幕相邻位置聚合，地点照片按 48 项加载。图库不提前请求地图数据。

### 照片清晰度与性能取舍

Timemark 参考链接的前几张照片使用 300×400 缩略图。本次仅图库卡片使用 COS 的 320/640 最长边衍生图，质量 80，浏览器按屏幕密度选档（最高 2x）；小图不放大。表格、地图列表、导出和原图预览保持原有资源策略。继续使用懒加载、异步解码、48 项分页、有限缓存和相邻页元数据预取。处理失败回退到原缩略图，不自动拉原图。已签名 URL、非 COS 域名和本地图片不追加处理指令，避免未知服务忽略参数而返回原图。

2026-09-15 同一张真实照片的采样：旧 x200 为 5,107 字节；320 档 8,926 字节；640 档 26,854 字节。该测量只说明样本体积，不代表所有照片或真实移动网络耗时。使用腾讯 COS 文档定义的等比缩小及质量参数：https://www-sg.tencentcloud.com/pt/document/product/1045/33713 。
