# tp_team_backend

登录会话不再按时间过期，`TOKEN_TTL_MS` 不再生效。为兼容现有数据库和客户端，
新会话的 `expiresAt` 返回 `9999-12-31T23:59:59.999Z`；现存旧会话在鉴权时更新为该值，
即使原到期时间已过也可继续使用，无需数据库迁移。

`/api/user/token/refresh` 校验会话后返回原 token，不创建新会话或撤销旧 token；重复或并发刷新不会改变凭证。
退出登录、删除账号以及手动删除会话仍会使凭证失效。
已被旧过期逻辑删除的会话、客户端已清除的 token 无法恢复，需要重新登录。
App 客户端如果自行检查旧 `expiresAt`，也应改为以服务端鉴权结果为准。
长期 token 具有持续访问权限，应妥善保存；泄露时需删除对应 Session 撤销。

鉴权回归测试：`node --test scripts/auth.test.cjs`。
